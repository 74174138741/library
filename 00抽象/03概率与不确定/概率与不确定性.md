第一章 表示

在现实世界中，决策系统几乎总是面临不完全信息和不确定性。智能体无法直接观测到环境的完整状态，也无法确定自己的动作会产生何种精确后果。
因此，我们需要一套形式化的语言来表示“相信什么”、“相信到什么程度”。


1.1 信念度与概率

概率论为信念度提供了量化的语言。

1.1.1 概率的基本性质

1. 非负性：$$\forall A \in \mathcal{F}, P(A) \geq 0$$                                                       没有负概率
2. 归一性：$$P(\Omega) = 1$$                                                                      概率空间内所有事情的可能性之和为1
3. 可数可加性：若 $$A_i$$ 两两互斥，则 $$P(\bigcup_{i=1}^\infty A_i) = \sum_{i=1}^\infty P(A_i)$$        对于互斥事件来说，一系列事件中至少发生其中一个的概率等于单独概率的累加。
4. 贝叶斯定理：

$$P(H \mid E) = \frac{P(E \mid H) P(H)}{P(E)}$$

可以通过他的变种进行记忆，也就是同时发生两个事件的概率等于各自的概率乘以各自概率下发生另外一个事情的概率。
$$P(H \mid E){P(E)} = {P(E \mid H) P(H)}$$

后验概率 = (似然度 × 先验概率) / 证据



1.1.2 信念度与频率解释

- 频率派（Frequentist）：概率是事件在无限重复实验中的极限频率。只适用于可重复现象。
- 贝叶斯派（Bayesian）：概率是信念度，可应用于一次性事件（如“明天是否下雨”、“某患者是否患癌”）。先验可来自专家知识或历史数据，通过证据更新得到后验。
在决策算法中，我们几乎总是采用贝叶斯观点，因为决策面临的是单次或有限次的真实世界交互。

1.1.3 为什么用概率表示信念？

1. 可组合性：通过联合分布与条件分布可系统地融合多源信息。
2. 可计算性：存在大量高效的近似推理算法（变分推断、MCMC、信念传播等）。
3. 决策理论基础：期望效用最大化（MEU）直接建立在概率之上。
4. 可学习性：参数与结构均可从数据中估计。


1.2 概率分布

概率分布描述了随机变量取不同值的概率或概率密度。

1.2.1 离散概率分布

对于离散随机变量 $$X$$，其概率质量函数（PMF）为：

$$p(x) = P(X = x), \quad \sum_x p(x) = 1$$

常见离散分布及其在决策中的应用：

分布
PMF 形式
典型应用场景
Bernoulli
$$p^x (1-p)^{1-x}$$
二分类决策（是/否、故障/正常）
Binomial
$$\binom{n}{k} p^k (1-p)^{n-k}$$
$$n$$ 次独立试验中的成功次数
Categorical
$$\pi_k$$（$$\sum \pi_k=1$$）
多类别状态表示（交通灯颜色）
Poisson
$$\frac{\lambda^k e^{-\lambda}}{k!}$$
单位时间内事件计数（到达、故障）
Geometric
$$(1-p)^{k-1}p$$
直到首次成功的等待时间

性质：期望 $$E[X]$$、方差 $$\text{Var}(X)$$、熵 $$H(X)$$ 是决策中常用的统计量。

1.2.2 连续概率分布

对于连续随机变量，采用概率密度函数（PDF）$$f(x)$$，满足：

$$P(a \leq X \leq b) = \int_a^b f(x) \, dx, \quad \int_{-\infty}^{\infty} f(x) \, dx = 1$$

常用连续分布：

- 均匀分布 Uniform$$(a,b)$$：无信息先验的常用选择。
- 高斯分布（正态分布）$$\mathcal{N}(\mu, \sigma^2)$$：
  $$f(x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(x-\mu)^2}{2\sigma^2} \right)$$
- 指数分布：建模等待时间（记忆less）。
- Gamma / Beta：共轭先验，在贝叶斯更新中起关键作用。
- Dirichlet：多元 Beta，用于类别分布的先验。
累积分布函数（CDF）$$F(x) = P(X \leq x)$$ 在置信区间计算和随机变量采样中非常重要。

1.3 联合分布

当系统涉及多个随机变量时，需要描述它们的联合行为。

1.3.1 离散联合分布

对于两个离散变量 $$X, Y$$，联合 PMF 是表格形式：

$$p(x, y) = P(X=x, Y=y)$$

边缘化（Marginalization）得到单个变量的分布：

$$p(x) = \sum_y p(x, y)$$

条件分布：

$$p(x \mid y) = \frac{p(x, y)}{p(y)}, \quad p(y) > 0$$

当变量数量增加时，联合分布的表格大小呈指数增长（$$O(|\mathcal{X}|^n)$$），这是维度灾难的根源，必须通过结构化表示来缓解。

1.3.2 连续联合分布

联合 PDF $$f(x, y)$$ 定义在 $$\mathbb{R}^2$$ 上。边缘化需要积分：

$$f(x) = \int_{-\infty}^{\infty} f(x, y) \, dy$$

高维连续联合分布的表示与计算更加困难，通常需要参数化假设（高斯、混合高斯、流模型等）。

1.4 条件分布

条件分布是表示“在已知某些变量取值的情况下，其他变量的分布”。

1.4.1 离散条件模型

最直接的表示是条件概率表（CPT）。对于变量 $$X$$ 依赖于父节点集合 $$\text{Pa}(X)$$：

$$\theta_{x \mid \mathbf{pa}} = P(X = x \mid \text{Pa}(X) = \mathbf{pa})$$

当父节点取值组合很多时，CPT 参数数量爆炸。可采用参数化条件模型降低复杂度。

1.4.2 条件高斯模型

当 $$Y$$ 为连续变量，$$X$$ 为离散变量（或反之），条件分布可建模为高斯：

$$P(Y \mid X = x) = \mathcal{N}(y; \mu_x, \Sigma_x)$$

不同 $$x$$ 对应不同的均值/协方差，形成混合高斯或高斯混合模型（GMM）的基础。

1.4.3 线性高斯模型

最常用的连续条件模型。假设：

$$X = \mathbf{w}^\top \mathbf{Y} + b + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

则条件分布为：

$$P(X \mid \mathbf{Y} = \mathbf{y}) = \mathcal{N}(x; \mathbf{w}^\top \mathbf{y} + b, \sigma^2)$$

线性高斯模型在卡尔曼滤波、线性动态系统、结构化预测中被广泛使用。

1.4.4 条件线性高斯模型

当多个连续变量之间存在线性高斯依赖，且可能混杂离散变量时，形成条件线性高斯（CLG）模型。这是许多混合动态贝叶斯网络的基础。

1.4.5 Sigmoid 模型

对于二值变量 $$X \in \{0,1\}$$，常用 logistic / sigmoid 函数建模条件概率：

$$P(X=1 \mid \mathbf{Y}=\mathbf{y}) = \sigma(\mathbf{w}^\top \mathbf{y} + b) = \frac{1}{1 + \exp(-(\mathbf{w}^\top \mathbf{y} + b))}$$

优点：
- 输出严格在 $$(0,1)$$ 区间
- 参数少（线性数量级）
- 可微，便于梯度优化
在神经网络、逻辑回归、以及贝叶斯网络中的二值节点建模中非常常见。也可推广到 softmax 用于多分类。

1.4.6 确定性变量

有时变量之间存在函数确定性关系，而非概率性。例如：

- $$Z = X + Y$$（确定性求和）
- $$C = \text{AND}(A, B)$$
在概率模型中可用退化分布（Dirac delta）表示：

$$P(Z \mid X, Y) = \delta(Z - (X + Y))$$

或直接在图结构中标记为确定性节点。确定性变量可大幅降低模型熵，并在推理时进行约束传播。
