# 时频复变换

同一条信号，可以在**时间**里看波形，在**频率**里看含哪些振荡，在**复数 s 平面**里看它会不会爆。三个镜头不是三套物理，是三种坐标系。

标准试验信号（阶跃、脉冲、正弦）见 [信号](../../02行为/感知/信号.md)。

---

## 1. 三副眼镜

```
时间 t / 拍 k          波形：什么时候发生
        │
        │  傅里叶：假定信号能写成振荡的叠加
        ▼
频率 ω / 数字频率 Ω    谱：有哪些快慢、各有多强
        │
        │  拉普拉斯：再乘一个 e^{-σt}，允许增长/衰减
        ▼
复平面 s = σ + jω      极点零点：稳不稳、快不快
```

- **时域**：控制指令、传感器曲线，直接画。
- **频域**：振动、滤波、带宽、正弦稳态。傅里叶把「周期振荡」当字母表。
- **复频域**：微分方程、传递函数、稳定性。拉普拉斯是傅里叶的加阻尼版。

「时频」不是第三种物理量，是问：**能量何时出现、又落在哪个频率**。傅里叶把整段历史揉成一根谱，时间被积分掉了；要同时保时间，得开窗（STFT）或换别的基。控制入门先把「全程傅里叶 / 拉普拉斯」吃透即可。

## 2. 连续 vs 离散：格子怎么划

时间和频率各自可以连续或离散，四格决定你用哪张公式。

| | 时间连续 `x(t)` | 时间离散 `x[k]` |
|---|---|---|
| **频率离散**（谱是一根根线） | **傅里叶级数 FS**：周期连续信号 | DFS：周期序列 |
| **频率连续**（谱是一条曲线） | **傅里叶变换 FT**：非周期、可积 | DTFT：一般无穷序列 |
| **频率再抽样、可上机** | 对 FT 数值积分 | **DFT / FFT**：有限长序列 |
| **带衰减/增长的复频率** | **拉普拉斯 `s`** | **Z 变换 `z`**（离散版拉普拉斯） |

采样：`x[k] = x(kT)`，`T` 为采样周期。数字频率 `Ω = ωT`（弧度/采样）。  
奈奎斯特：信号里高于 `π/T`（即 `f_s/2`）的频率会折回来假扮低频，先抗混叠再采样。

对照记忆：

```
周期、连续时间  ──FS──►  离散谱线
非周期、连续    ──FT──►  连续频谱
FS 的周期→∞    ──►  就变成 FT（谱线挤成一片）
FT 再乘 e^{-σt}──►  拉普拉斯
连续 L 里 s = e^{sT} 的抽样 ──► Z 变换
```

## 3. 时域 / 频域各自在说什么

连续信号的一对（傅里叶变换，工程常用角频率 `ω`）：

$$
X(j\omega)=\int_{-\infty}^{\infty} x(t)\,e^{-j\omega t}\,dt
\qquad
x(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty} X(j\omega)\,e^{j\omega t}\,d\omega
$$

`e^{jωt} = cos ωt + j sin ωt`：每个频率是一个转圈。`X(jω)` 的模 = 这个圈的振幅，幅角 = 起点相位。

离散有限长（DFT，计算机里真正跑的）：

$$
X[m]=\sum_{k=0}^{N-1} x[k]\,e^{-j 2\pi mk/N}
\qquad
x[k]=\frac{1}{N}\sum_{m=0}^{N-1} X[m]\,e^{j 2\pi mk/N}
$$

`N` 个时间点 ↔ `N` 根谱。FFT 只是算 DFT 的快算法。

时频对照（线性时不变）：

| 时域 | 频域 / 复频域 |
|---|---|
| 卷积 `x * h` | 相乘 `X·H` |
| 求导 `ẋ` | 乘 `jω` 或 `s` |
| 延迟 `x(t-τ)` | 乘 `e^{-jωτ}` / `e^{-sτ}` |
| 冲激 `δ(t)` | `1` |
| 阶跃 `1(t)` | `1/(jω)` 或 `1/s`（加 ROC） |
| 正弦稳态 | 只看 `s = jω` 上的 `G(jω)` |

所以滤波、带宽、正弦跟踪，用频域更省事；波形谁先谁后、超调，仍要回到时域（见信号篇动态指标）。

## 4. 傅里叶级数：周期信号的字母表

只适用于**周期**连续信号：`x(t+T)=x(t)`，基频 `ω₀ = 2π/T`。

它说：周期波 = 直流 + 一串倍频正弦。两种写法同一件事。

三角形式：

$$
x(t)=a_0+\sum_{n=1}^{\infty}\bigl(a_n\cos n\omega_0 t+b_n\sin n\omega_0 t\bigr)
$$

指数形式（更干净，和拉普拉斯同一套 `e^{st}`）：

$$
x(t)=\sum_{n=-\infty}^{\infty} c_n\, e^{j n\omega_0 t}
\qquad
c_n=\frac{1}{T}\int_{T} x(t)\,e^{-j n\omega_0 t}\,dt
$$

`c_n` 是第 `n` 根谱线的复数坐标：`|c_n|` 振幅，`arg c_n` 相位。谱**只在 `nω₀` 上有值**，其余频率为零——周期在频域里就是「离散的梳子」。

用得上的事实：

- 方波、锯齿只含特定谐波；滤波器切掉高 `n`，波形变圆（Gibbs：在跳变处会永远留一点过冲）。
- 周期方波驱动电机 / 逆变器：噪声往往在开关频率的倍频上，级数直接告诉你该滤哪根。
- 周期 → 无穷：`T→∞`，`ω₀→0`，梳子齿距变成连续的 `dω`，级数变成傅里叶变换。

离散周期序列把积分换成求和，叫 DFS；一段录音当「这一段就是一个周期」做 DFT，本质上是在假装它周期延拓——泄漏、加窗都是这个假装带来的。

## 5. 拉普拉斯变换：给傅里叶加上衰减

傅里叶要求信号绝对可积。阶跃、斜坡、不稳定的 `e^{at}`（`a>0`）常常不满足。办法：先乘一个衰减 `e^{-σt}`，再做傅里叶。令 `s = σ + jω`：

$$
X(s)=\int_{0^-}^{\infty} x(t)\,e^{-st}\,dt
\qquad
x(t)=\frac{1}{2\pi j}\int_{\sigma-j\infty}^{\sigma+j\infty} X(s)\,e^{st}\,ds
$$

工程几乎都用**单边**（`0⁻` 起，把 `t=0` 的冲激算进去）。`σ` 要足够大，积分才收敛——这就是收敛域 ROC。

和傅里叶的关系：若 ROC 包含虚轴 `σ=0`，则 `X(s)|_{s=jω}` 就是傅里叶变换。稳定系统的频率响应 = 传递函数在虚轴上走一遭。

### 几张必须会背的表

| `x(t)`（`t≥0`） | `X(s)` |
|---|---|
| `δ(t)` | `1` |
| `1(t)` 阶跃 | `1/s` |
| `t` 斜坡 | `1/s²` |
| `e^{-at}` | `1/(s+a)` |
| `sin ωt` | `ω/(s²+ω²)` |
| `cos ωt` | `s/(s²+ω²)` |
| `ẋ(t)` | `sX(s) - x(0⁻)` |
| `x(t-τ)1(t-τ)` | `e^{-sτ} X(s)` |
| 卷积 `x*h` | `X(s)H(s)` |

最后一行就是传递函数：`G(s) = Y(s)/U(s)`（零初始）。冲激进、`G(s)` 出——和信号篇「脉冲响应是指纹」对上。

### s 平面怎么读

`s = σ + jω`：横轴衰减/增长，纵轴振荡频率。

```
        Im
         │  × 极点：分母的根，系统自己的模态
         │
─────────┼──────── Re
         │  ○ 零点：分子的根，会抵消某些模态
         │
```

- 极点在左半平面 `σ<0` → 对应 `e^{σt}` 衰减 → **稳定**。
- 在虚轴上 → 等幅振荡（需单根等额外条件）。
- 在右半平面 → 指数炸。
- 离虚轴越远（`|σ|` 大）→ 衰减越快 → 调节时间越短。
- 一对共轭极点的 `ω` 大 → 振荡快；阻尼比由夹角决定。

微分方程 `ẍ + 2ζω_n ẋ + ω_n² x = ω_n² u` 变成 `G(s) = ω_n² / (s² + 2ζω_n s + ω_n²)`。超调、调节时间那些动态指标，是这对极点在时域的投影。

### 离散对应：Z 变换

`X(z) = Σ x[k] z^{-k}`，`z = e^{sT}`。单位圆 `|z|=1` 扮演虚轴：稳定极点在单位圆内。差分方程、离散控制器用它，和拉普拉斯同一套极点故事，只是平面换成了圆。

## 6. 选哪一把

| 你手头的问题 | 用 |
|---|---|
| 周期振动、谐波、逆变器开关纹波 | 傅里叶级数 |
| 频谱、滤波、带宽、Bode（系统已稳定） | FT / `G(jω)` |
| 计算机里一段采样 | DFT / FFT（注意窗和泄漏） |
| ODE、传递函数、稳定性、PID、根轨迹 | 拉普拉斯 |
| 采样控制、离散伺服 | Z 变换 |
| 「哪一段时间出现了哪个频率」 | STFT / 小波（傅里叶做不到） |

最小闭环：

1. 时域画阶跃响应（信号篇的 `t_r、σ%、t_s`）。
2. 用拉普拉斯写成 `G(s)`，看极点在不在左边。
3. 需要抗振、选截止频率时，令 `s=jω` 看 Bode。
4. 上机采样后，FFT 看实测谱是否和 Bode 一致。
