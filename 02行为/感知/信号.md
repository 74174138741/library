# 信号

信号是**随时间（或空间）变化的量**。传感器读数、参考轨迹、控制输入，都是信号。控制里不拿真实世界的乱七八糟波形开刀，而是用几类**标准形状**去试系统；试完用**静态 / 动态指标**给这条响应打分。

变换视角（傅里叶、拉普拉斯）见 [时频复变换](../../00抽象/02函数与变换/时频复变换.md)。

---

## 1. 心智模型

```
参考 r(t) ──► 系统 ──► 输出 y(t)
                │
                └── 误差 e = r - y
```

问系统「好不好」，等价于：喂它一个认识的输入，看 `y(t)` 追得上不算、追得快不快、稳不稳。

连续时间写 `x(t)`，离散采样写 `x[k] = x(kT)`。下面的形状两边都有对应物。

---

## 2. 常见模式（控制里真正会喂的）

按「能量集中在哪」记：一个点、一条边、一条斜线、一个频率。

### 阶跃（step）——最常用的考卷

```
x(t)
  │        _____________
  │       |
  │_______|
  └──────────────── t
          t=0
```

连续：`1(t)` 或 `u(t)`，`t<0` 为 0，之后为 1。  
离散：`u[k]`，`k≥0` 为 1。

像：开关突然打开、位置指令从 0 跳到 10 cm、速度给定突变。  
用来考：**稳态准不准、超调大不大、多久稳住**。教科书里的上升时间、超调量，默认都是对着阶跃说的。

机器人里纯阶跃往往太狠（电机跟不上），轨迹规划会把它削成梯形 / S 曲线；但**评价控制器**时，仍然经常对闭环做阶跃实验。

### 脉冲 / 冲激（impulse）——敲一下

```
x(t)
  │  |
  │  |
  │__|___________ t     连续：δ(t)，宽→0，面积=1
```

连续 Dirac：`∫ δ(t) dt = 1`，`t≠0` 处为 0。  
离散：`δ[k] = 1`（仅 `k=0`），否则 0。面积不必做成无穷高，一个采样点的 1 就是冲激。

像：碰撞、敲击、离散里「只在这一拍给一个 1」。  
用来考：**脉冲响应 = 系统的指纹**。线性系统里，任意输入 = 冲激响应的卷积。拉普拉斯里 `L{δ(t)} = 1`，传递函数 `G(s)` 本身就是冲激响应的变换。

工程上很难打出理想 δ，常用**窄脉宽、面积为 1 的方脉冲**代替。

### 斜坡（ramp）——匀速跟踪

`x(t) = t · 1(t)`。像匀速直线运动的位置指令、斜坡升温。  
用来考：系统能不能跟上**匀速变化**（I 型系统对斜坡的稳态误差是有限值，0 型会越拉越大）。

### 抛物线（parabola）——匀加速

`x(t) = t²/2 · 1(t)`。像匀加速位置。再苛刻一档，用来看加速度跟踪。

### 正弦（sinusoid）——一个频率

`x(t) = A sin(ωt + φ)`。  
用来考：**频率特性**——这个 ω 下增益多少、相位落后多少。扫一串 ω 就得到 Bode 图。感知侧：振动、交流、周期性干扰。

### 控制里另外几类常客

| 形状 | 长什么样 | 什么时候用 |
|---|---|---|
| 方波 / 脉冲串 | 阶跃的周期版 | 反复正反转、看对称性和疲劳 |
| 矩形脉冲 | 有宽度的「敲一下」 | 近似冲激；有限能量输入 |
| 梯形速度 | 加速–匀速–减速 | 关节 / 底盘速度规划，比纯阶跃温和 |
| S 曲线 | 加速度也连续 | 减少冲击、保护机械 |
| 饱和后的阶跃 | 爬到限幅就平 | 执行器限幅后的真实输入 |
| 白噪声 / PRBS | 看起来乱 | 系统辨识，把各频率都打醒 |

阶跃、斜坡、抛物线合称**典型输入**，对应位置 / 速度 / 加速度三级跟踪。脉冲用来认系统，正弦用来认频率。

## 3. 先分清：评的是信号，还是响应

| 对象 | 你在问 | 典型数字 |
|---|---|---|
| 传感器读数（感知，静态） | 真值不动时，读数准不准 | 量程、灵敏度、线性度、迟滞、重复性、精度、死区、零偏 |
| 信号随时间（感知，动态） | 波形干净吗、跟得上吗 | SNR、延迟、带宽 |
| 系统对标准输入的响应（控制） | 追参考追得怎样 | 稳态误差、超调、调节时间 |

下面两套指标都按**静态 / 动态**切开。控制实验里默认看的是**阶跃响应**。

---

## 4. 静态指标：最后停在哪



系统已经进入稳态（`t → ∞`，振荡收完）之后，只剩「准不准」。

对参考 `r`、输出 `y`：

```
稳态值     y(∞)
稳态误差   e_ss = r(∞) - y(∞)
```

| 指标 | 含义 | 阶跃时 |
|---|---|---|
| 稳态值 | 最后趴在哪 | 希望等于给定幅值 |
| 稳态误差 `e_ss` | 还差多少 | 位置阶跃：希望 0 |
| 静差 / 残差率 | `e_ss / r(∞)` | 有时用百分比 |
| 静态增益 | `y(∞) / u(∞)` | 开环「放大倍数」 |

和典型输入的关系（单位反馈、开环含积分的个数 = 型别）：

| 输入 | 0 型（无积分） | I 型 | II 型 |
|---|---|---|---|
| 阶跃 | 常值误差 | 0 | 0 |
| 斜坡 | 越来越大 | 常值误差 | 0 |
| 抛物线 | 越来越大 | 越来越大 | 常值误差 |

上面是**控制器看闭环**。感知侧另有一套，输入已经停住、只看读数相对真值：传感器静态指标。

### 传感器静态指标（工程）

真值 `x` 固定（或极慢变），看读数 `y`。数据手册上的「精度、线性、迟滞」几乎都是这条 **y–x 校准曲线** 上抠出来的，不看上升时间。

```
y（读数）
  │     上行 /
  │        /  ← 迟滞：来回不是同一条
  │       / 下行
  │      /
  │_____/___________ x（真值）
        量程
```

1. **量程**  
   保证指标仍成立的输入区间，如力传感器 ±200 N、编码器 0～360°。超出叫超量程：读数可能饱和、损坏、指标作废。手册里的 `%F.S.` 以**满量程**为分母，同样 ±0.1% F.S.，量程越大绝对误差越大。

2. **灵敏度**  
   校准曲线的斜率：`Δy / Δx`。IMU 加速度计多少 LSB/g、力矩传感器多少 V/N·m。太钝则小信号看不清，太尖则容易饱和。非线性传感器灵敏度随工作点变，手册给的常是某点或平均斜率。

3. **分辨率（分辨力）**  
   能可靠分开的最小输入变化。数字侧常被量化成 1 LSB：12 bit 的 10 V 量程 ≈ 2.4 mV/bit。模拟侧还受噪声限制——噪声比 1 LSB 还大，多出来的 bit 是假的。编码器 CPR、激光的最小可辨距离，都是它。

4. **线性度**  
   校准曲线相对某条拟合直线（端点连线或最小二乘）的最大偏离，多写成 `%F.S.`。系统辨识、用常数增益去标定时，线性度差 = 你当它是直线会在两端系统性说错。

5. **迟滞**  
   同一输入，从大往小走和从小往大走，读数不一样。齿轮间隙、弹性件内摩擦、磁滞都是这个。来回运动的关节力矩、力控接触，迟滞会在过零附近变成死区感。

6. **重复性**  
   同条件、同方向、反复逼近同一点，读数能散多开。散得小叫精密（precision），不等于准。靶上枪枪打在一起但偏在十环外：重复性好、准确度差。

7. **准确度 / 精度**  
   读数相对真值能偏多少，通常是线性度、迟滞、重复性等的**综合包络**（有的手册按方和根合成）。买传感器先看这一条够不够你的公差；拆开看时再追究是偏了还是晃了。注意中文「精度」有时被用来兼指 accuracy 和 precision，对指标时要看英文或定义。

8. **阈值与死区**  
   阈值：刚能引起可察觉输出变化的最小输入。死区：输入动一截、输出几乎不变的区间。静摩擦、齿轮隙、数字比较器都造成死区。控制里过零振荡、小误差消不掉，经常是它。

9. **零偏与漂移**  
   输入应为 0 时输出不是 0 = **零偏（bias）**，IMU 角速度常值偏、力传感器空载不为零。偏会随时间、温度慢慢爬 = **漂移**。零偏是当下一个数，漂移是这个数还会走。开机校准能扣掉当前零偏，扣不掉温度再漂的那截。

现场怎么读手册：先看量程盖不盖得住、准确度进不进公差；再看分辨率是否被噪声吃掉；力/力矩还要看迟滞；IMU 要看零偏和温漂。线性度只在你准备用一条直线标定时才致命。

和控制静态的关系：传感器的零偏、死区会直接变成闭环里消不掉的 `e_ss`；这时不是型别不够，是测量这条腿先歪了。

## 5. 动态指标：中间怎么走过来

阶跃来了之后、到达稳态之前，看这条曲线的形状。

```
y
  │          峰值 yp
  │         /\
  │        /  \___ 进入 ±Δ 带宽，此后算稳住
  │       /         y(∞)
  │      /
  │_____/________________ t
        td  tr   tp    ts
```

常用定义（阶跃幅值已归一，或相对 `y(∞)`）：

| 指标 | 符号 | 怎么量 | 你在乎什么 |
|---|---|---|---|
| 延迟时间 | `t_d` | 第一次到 `0.5 y(∞)` | 反应有多迟钝 |
| 上升时间 | `t_r` | 常用 `0.1→0.9 y(∞)`；无超调也可用 `0→1.0` | 爬得快不快 |
| 峰值时间 | `t_p` | 第一次冲到峰值 | 振荡有多「脆」 |
| 超调量 | `σ%` | `(y_p - y(∞)) / y(∞) × 100%` | 会不会冲过头 |
| 下冲 | — | 先往反方向掉 | 非最小相位、柔性、反作用 |
| 调节时间 | `t_s` | 进入并留在 `y(∞)±2%`（或 ±5%）的时间 | 多久能用 |
| 振荡次数 | — | 进带宽前晃了几下 | 阻尼够不够 |

二阶欠阻尼时有近似（阻尼比 `ζ`、自然频率 `ω_n`）：

- 超调 `σ% ≈ 100 exp(-ζπ / √(1-ζ²))`
- `t_p ≈ π / (ω_n √(1-ζ²))`
- `t_s(±2%) ≈ 4 / (ζ ω_n)`

口诀：`ζ` 大 → 超调小、更「肉」；`ω_n` 大 → 同样 ζ 下更快。两者经常打架：更快往往更容易超调。

正弦输入下的动态指标换成**带宽**（增益掉到 -3 dB 的频率）、**相位裕度 / 增益裕度**——那是频域的动态，细节在变换篇。

## 6. 综合指标（把整条误差曲线收成一个数）

不想只看某一个时刻，就把 `e(t)` 积分掉：

| 名称 | 公式意味 | 偏向 |
|---|---|---|
| IAE | `∫|e| dt` | 普通总和 |
| ISE | `∫ e² dt` | 狠狠罚大误差 |
| ITAE | `∫ t|e| dt` | 越晚还在偏，罚得越重（常用） |
| ITSE | `∫ t e² dt` | 又罚大又罚晚 |

调参时可以拿 ITAE 当目标；汇报性能时仍要同时给 `e_ss、σ%、t_s`，单看一个积分看不出是慢还是晃。

## 7. 现场怎么用

1. **认系统**：脉冲（或短矩形脉冲）→ 看脉冲响应；或阶跃 → 看会不会振荡。
2. **认跟踪**：位置用阶跃，速度用斜坡，加速度用抛物线。
3. **认频率**：正弦扫频 / chirp。
4. **认指标**：先看静态 `e_ss`（型别对不对），再看动态 `t_r、σ%、t_s`（阻尼和带宽），不够再看 ITAE。
5. **机械上别用裸阶跃当指令**：规划层用梯形 / S 曲线；评价层仍可用阶跃测闭环。

感知链路里同一套词：滤波器的阶跃响应 = 它有多钝；延迟时间往往就是控制里要用的「测量滞后」。
