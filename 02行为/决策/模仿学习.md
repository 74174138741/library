# 模仿学习

观察学习 / 模仿学习：先看人（或示教）怎么走，再让机械臂走出「同一类事」，而不是从零靠奖励自己试。这份笔记对应「结合语义约束与几何约束」那条线：几何管形状、碰撞、关节能不能到；语义管这件事相对哪个物体、哪个坐标系才算做对。

原理上的价值函数、策略梯度见 [强化学习](强化学习.md)。下面是轨迹怎么从示教变成可泛化模型。

图片原件在 [模仿学习-附件](模仿学习-附件/)。公式能写清的已写进正文，流程图仍挂图。

## 思路

要同时学出示教里的**自由运动**和**约束运动**（贴着桌面推、绕开障碍），一组轨迹不够，需要多组。

整条流水线：

```
示教几条
  → DMP 做时间/空间拉伸，生成很多候选轨迹
  → 碰撞检测丢掉不能走的（几何约束）
  → 用任务参数化高斯混合模型（TP-GMM）吃下合法轨迹，抽出「这件事相对物体怎么摆」的特征（语义/任务参数）
  → 高斯混合回归 GMR：物体换位置后，再吐出一条新轨迹
```

一句话：DMP 负责「把一条示教变成一族像它的曲线」；GMM/GMR 负责「从一族曲线里读出任务结构，再按新摆放生成」。

示教 → 概率模型 → 平滑轨迹，空间上长这样：

![示教到 GMM 再到 GMR](模仿学习-附件/image%201.png)

左：三条有抖动的示教；中：几个椭圆罩住局部密度（GMM）；右：一条平滑任务轨迹，周围是方差带（GMR）。

## DMP

DMP（Dynamic Movement Primitive，动态运动基元）：**用一个动力系统来表示轨迹**，而不是存一串时间戳路点。好处是：目标点挪一下、快慢变一下，弹簧还是会把你拉到终点，形状由学来的外力项负责。

机械臂真实动力学：

$$M(q)\ddot{q} + C(q,\dot{q})\dot{q} + G(q) = \tau$$

逆动力学就是反过来：已知要走的 $q,\dot{q},\ddot{q}$，求该加多大关节力矩。DMP 不直接解这套刚体方程，而是在**任务空间位置 $x$** 上用一个二阶弹簧–阻尼系统去模仿「朝目标走」的手感：

![含强迫项的二阶系统](模仿学习-附件/image%207.png)

$$M\ddot{x} + D\dot{x} + Kx = f$$

落到 DMP 常用写法（$\tau$ 管时间尺度，$g$ 是目标点，$f$ 是从示教里学到的形状）：

$$\tau^2 \ddot{x} = K(g - x) - B\tau\dot{x} + f$$

把示教轨迹 $x_d(t)$ 当成系统已经走出来的输出，反求当时需要的强迫力（学习目标）：

$$\tau^2 \ddot{x}_d + B\tau\dot{x}_d + K(x_d - g) = f_{\mathrm{target}}$$

若 $f$ 直接写成时间 $t$ 的函数，换速就会对不上拍。所以引入**相位 $s$**，让时间可以整体拉伸：

$$\tau \dot{s} = -\alpha_s s \qquad \Rightarrow \qquad s(t) = e^{-\alpha_s t / \tau}$$

$s$ 从 1 慢慢掉到 0，当一条不依赖绝对时钟的进度条。强迫项用一堆高斯基函数在 $s$ 上加权（RBF 拟合能力很强）：

$$\psi_i(s) = \exp\left(-\frac{(s-c_i)^2}{2\sigma_i^2}\right)$$

$$f(s) = \frac{\sum_i w_i \psi_i(s)}{\sum_i \psi_i(s)}\, s$$

（空间缩放时后面常再乘 $(g-x_0)$。）$w_i$ 由示教的 $f_{\mathrm{target}}$ 最小二乘求出。换 $\tau$ 只改快慢，形状跟着 $s$ 走，这就是时间上的泛化。

### 从示教到上臂

离线建模、在线执行：

![DMP 离线捕捉与在线生成](模仿学习-附件/image%2016.png)

1. 动捕 / 相机采人体或示教器轨迹  
2. 离线拟合 DMP 参数（主要是 $\{w_i\}$）  
3. 在线：当前时间 $t$ + 权重 → DMP 推出笛卡尔路径 $x$  
4. 逆解成关节角 $q$，交给位控跟随  

DMP 模型是离线练好的；上臂时只做前向积分和 IK，不再重新拟合。

### 调参

三类旋钮：

| 类 | 参数 | 管什么 |
|---|---|---|
| 动力学（手感/稳不稳） | $K$, $B$ | 弹簧有多硬、阻尼有多大 |
| 时间（快慢） | $\tau$, $\alpha_s$ | 整段动作时长、相位掉得急不急 |
| 表达能力（贴不贴示教） | $N$, $c_i$, $\sigma_i$, $w_i$ | 基函数多少、摆哪、多宽；权重靠学习 |

经验：

- $K = 100\sim 1000$，$B = 2\sqrt{K}$（临界阻尼，少晃）
- $\tau$ 小 → 快；$\tau$ 大 → 慢。最省事：$\tau$ 取示教时长
- $\alpha_s$ 大：更快贴近目标；小：进度更匀
- $c_i$：第 $i$ 个高斯在相位轴上的中心，平移就等于把这段「外力」挪到别的进度
- $\sigma_i$ 大：各基函数重叠多、更糊；小：更局部、拐弯更锐
- $w_i$：每个基函数对外力的贡献，用轨迹误差最小二乘学
- $g$：终点。改 $g$，弹簧会把整条曲线拽向新目标（空间泛化）
- $N$ 太小拟合不了，太大过拟合还会抖。一般 $20\sim 50$，弯多的轨迹 $50\sim 100$。经验：$N$ 大约跟「弯曲复杂度」成正比

建议按这个顺序拧，不要一上来全局乱搜：

1. 先钉死动力学：$K=100$，$B=20$（或 $B=2\sqrt{K}$）  
2. 再设时间：$\tau=$ 示教时长，$\alpha_s=4$  
3. 基函数：$N=30$，$c_i$ 均匀铺开，$\sigma$ 取常数  
4. 最小二乘学 $w_i$  
5. 看跟踪误差和是否振荡，再动 $N$ 或 $K$

## GMM 高斯混合模型

DMP 能从一条示教变出很多条。这些条快慢不一，先用 **DTW（动态时间规整）** 把时间轴对齐：两条曲线哪一段对哪一段，按距离最小来弯折时间，对齐后再当同一套「进度」上的样本。

对齐后的多条轨迹，用 GMM 描述「某一进度、某一位置，点有多常出现」。GMM = 若干个局部高斯加权相加：每个高斯的均值说「这一段轨迹中心在哪」，协方差说「这一段有多散」。

$$P(x\mid\theta)=\sum_{k=1}^{K}\alpha_k\,\phi(x\mid\theta_k)$$

$$\phi(x\mid\theta_k)=\frac{1}{\sqrt{(2\pi)^D|\Sigma_k|}}\exp\left(-\frac{1}{2}(x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k)\right)$$

| 符号 | 白话 |
|---|---|
| $K$ | 用几口钟叠这条轨迹 |
| $\alpha_k$ | 第 $k$ 口钟的混合权重（这块模式有多常见） |
| $\mu_k$ | 钟的中心 |
| $\Sigma_k$ | 钟有多扁、朝哪歪 |

单个高斯能用极大似然直接写出解析解。混在一起时，每个点属于哪一口钟是隐变量，要用 **EM 迭代**。

### DTW 时间对齐

示教快慢不同，直接平均会把弯儿抹糊。DTW 允许时间轴局部拉伸，让相似的空间形状对齐到相似的进度，再交给 GMM。

### GMM 轨迹泛化

流程：DMP 泛化出一簇轨迹 → DTW 对齐 → GMM 学这簇点的概率密度 → 后面 GMR 再按条件吐平滑路径。

### K-Means 轨迹初始化

EM 对初值敏感。K-Means 先按距离把点粗分成 $K$ 堆，给每个高斯一个说得通的 $\mu,\Sigma$，EM 收敛更快、更稳。每堆大致对应轨迹的一段局部模式。

输入样本 $D=\{x_1,\ldots,x_m\}$，随机挑 $k$ 个当初始质心 $\{\mu_1,\ldots,\mu_k\}$，然后转圈：

1. 每个点进离它最近的堆：$\lambda_i=\arg\min_j\|x_i-\mu_j\|^2$  
2. 质心改成堆内平均：$\mu_j=\frac{1}{|C_j|}\sum_{x\in C_j}x$  
3. 质心几乎不动就停，输出划分 $C=\{C_1,\ldots,C_k\}$

### EM（在 K-Means 之后）

目标：让整条轨迹点在这套高斯下出现的可能性尽量大（极大似然）

$$\mathcal{L}=\prod_{n=1}^{N}p(x_n\mid\{\pi_i,\mu_i,\Sigma_i\})$$

**E 步**：点 $x_n$ 有多大把握算第 $i$ 个高斯的（责任 $\gamma_{ni}$，0 到 1）：

$$\gamma_{ni}=\frac{\pi_i\mathcal{N}(x_n\mid\mu_i,\Sigma_i)}{\sum_{j=1}^{M}\pi_j\mathcal{N}(x_n\mid\mu_j,\Sigma_j)}$$

**M 步**：按责任重新摆钟、改胖瘦、改权重：

$$\mu_i=\frac{\sum_n\gamma_{ni}x_n}{\sum_n\gamma_{ni}}$$

$$\Sigma_i=\frac{\sum_n\gamma_{ni}(x_n-\mu_i)(x_n-\mu_i)^\top}{\sum_n\gamma_{ni}}$$

$$\pi_i=\frac{\sum_n\gamma_{ni}}{N}$$

$\mu$：这段轨迹最可能的中心；$\Sigma$：这段有多「厚」；$\pi$：这种局部模式占多少比重。E→M 直到收敛。每个高斯是局部轨迹分布，加起来就是整条 GMM。

### TP-GMM

Task-Parameterized GMM：任务参数化高斯混合。核心是**多个坐标系一起说话**，而不是只在世界系里拟合一条绝对路径。

抓杯子：杯子坐标系里，轨迹总是「从上方伸进去」；世界系里杯子挪了，绝对坐标全变。每个参考系（起点、物体、目标）各维护一套 GMM，只描述「在我这个系里轨迹长什么样」。执行时各系相对位姿会变，把各系里的高斯变回世界系再融合，起点/目标变了仍能长出合理轨迹——这就是任务参数（语义：相对谁）和几何（各系里的形状）的结合。

**和普通 GMM 的关键差别：**

1. **多个坐标系**：每个 GMM 对应一个 Frame，只看该系下的轨迹样子。  
2. **乘积融合，不是简单加权求和。** 第 $i$ 个高斯在各系变到同一世界系后：

$$\Sigma_i^{-1}=\sum_j\bigl(\Sigma_i^{(j)}\bigr)^{-1}$$

$$\mu_i=\Sigma_i\sum_j\bigl(\Sigma_i^{(j)}\bigr)^{-1}\mu_i^{(j)}$$

精度高（协方差小、更确定）的坐标系说话更响。可以想成：每个系提一个「轨迹该在哪」的建议，融合结果是这些建议按把握加权后的综合最优点。

### 高斯混合回归 GMR

GMM 给出「点大概出现在哪片云」；GMR 是在这片云上做**条件预测**：给定时间 $t$（或某个状态），问位置最可能在哪，以及有多不确定。

输入：已训练的 $(\pi_i,\mu_i,\Sigma_i)$，加上条件变量 $x_c$（通常是时间或进度）。  
输出：目标变量 $x_t$（位置/位姿）的均值和协方差。

把每个高斯拆成「条件块 + 目标块」的联合分布：

$$p(x_c,x_t)=\sum_{i=1}^{M}\pi_i\,\mathcal{N}\left(
\begin{bmatrix}x_c\\x_t\end{bmatrix}
\Big|
\begin{bmatrix}\mu_i^c\\\mu_i^t\end{bmatrix},
\begin{bmatrix}\Sigma_i^{cc}&\Sigma_i^{ct}\\\Sigma_i^{tc}&\Sigma_i^{tt}\end{bmatrix}
\right)$$

条件均值、协方差（加权后就是一条带带宽的平滑轨迹）：

$$\beta_i(x_c)=\frac{\pi_i\mathcal{N}(x_c\mid\mu_i^c,\Sigma_i^{cc})}{\sum_j\pi_j\mathcal{N}(x_c\mid\mu_j^c,\Sigma_j^{cc})}$$

$$\hat x_t=\sum_{i=1}^{M}\beta_i(x_c)\bigl[\mu_i^t+\Sigma_i^{tc}(\Sigma_i^{cc})^{-1}(x_c-\mu_i^c)\bigr]$$

$$\hat\Sigma_t=\sum_{i=1}^{M}\beta_i^2(x_c)\bigl[\Sigma_i^{tt}-\Sigma_i^{tc}(\Sigma_i^{cc})^{-1}\Sigma_i^{ct}\bigr]$$

$\beta_i$ 是「这个条件下第 $i$ 口钟该负多大责」。任务边界有不确定性时，用这套概率加权比死磕一条平均线更稳。

**TP-GMM 和 GMR 不是互相替代：**

| | TP-GMM | GMR |
|---|---|---|
| 加权对象 | 各坐标系里的同一号高斯 | 同一坐标系里不同号高斯 |
| 权重从哪来 | 精度矩阵（谁更确定） | 条件责任 $\beta_i$ |
| 作用 | 多系融合 → 全局轨迹分布 | 给定条件 → 最可能的轨迹点 |
| 结果 | 融完后的新 GMM | 一个点：均值 + 方差 |

TP-GMM = 多视角轨迹融合，得到新分布。  
GMR = 在这个分布里，按条件查出最可能的位置。

### 和高斯过程回归 GPR 的关系

原文里还对比了 **GPR**（高斯过程回归）。它不是 GMM 那种「先聚类再回归」，而是一种**非参数**方法：任意有限个输入点上的函数值，合在一起服从一个多元高斯。

$$h(x)\sim\mathcal{GP}\bigl(m(x),\,k(x,x')\bigr)$$

$m(x)$ 均值，常取 0；$k$ 核函数，管两点有多像。常用 RBF：

$$k(x,x')=\sigma_f^2\exp\left(-\frac{\|x-x'\|^2}{2l^2}\right)$$

有训练对 $(X,y)$ 时，新点 $X_*$ 的预测：

$$\hat h_*=K(X_*,X)K(X,X)^{-1}y$$

$$\mathrm{Var}(\hat h_*)=K(X_*,X_*)-K(X_*,X)K(X,X)^{-1}K(X,X_*)$$

既给值，也给不确定性。

核决定函数「长什么样」：

| 核 | 特性 | 场景 |
|---|---|---|
| RBF / Gaussian | 光滑、连续、无周期 | 多数回归 |
| Matérn | 平滑度可调，能贴不太光滑的曲线 | 工程、物理 |
| Linear | 线性趋势 | 线性回归 |
| Periodic | 周期 | 周期信号 |

训练 GPR = 调核超参 $\theta=\{l,\sigma_f,\sigma_n,\ldots\}$，不是调一层层神经网络权重。

| 超参 | 含义 |
|---|---|
| $l$ | 长度尺度：小则曲线拧得急，大则平 |
| $\sigma_f^2$ | 输出方差：函数能抖多高 |
| $\sigma_n^2$ | 观测噪声：训练点允许偏多少，加在 $K$ 对角 |

做法：构造 $K_\theta=k_\theta(X,X)+\sigma_n^2 I$，最大化对数边缘似然

$$\log p(y\mid X,\theta)=-\frac12 y^\top K_\theta^{-1}y-\frac12\log|K_\theta|-\frac n2\log 2\pi$$

对 $\theta$ 求导优化。参数一定，$K$ 一定，整个高斯就定了，任意测试点都能给出均值+方差。调 $l,\sigma_f,\sigma_n$ 就是在调预测曲线和不确定性带宽。

GMR 吃的是「已经混好的几口高斯」；GPR 吃的是「核定义的函数先验」。轨迹模仿这条线上，示教簇用 GMM+GMR（再加 TP 做多系）更贴本文流水线；GPR 适合样本少、还想要平滑带不确定度的回归。

## 串起来怎么用

1. 示教若干条（自由段 + 约束段都要有）。  
2. DMP 学形状，改 $\tau$/$g$ 生成候选，碰撞检测丢掉几何上非法的。  
3. DTW 对齐 → K-Means 初始化 → EM 得到 GMM。  
4. 有多个任务坐标系就上 TP-GMM，按精度融合。  
5. GMR 按时间/进度吐新位置；物体挪了，改任务参数再回归。  
6. 笛卡尔轨迹逆解到关节，位控跟踪。

语义约束落在「相对哪个物体、哪个 Frame」；几何约束落在「碰撞、可达、弹簧能否稳到 $g$」。观察学习做的是：从示教里把这两类约束变成 DMP 权重和 GMM 参数，而不是手写一条死轨迹。
