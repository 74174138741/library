# 强化学习

强化学习：智能体跟环境来回互动，根据打分改自己的行为，把长期总分拉高。

和监督学习的差别：没有人告诉你这一步对不对，只有晚到的奖励；对了要多做，错了要少做。

两种基本模式：

- **在线策略（on-policy）**：边走边学，走路的策略和学习的策略是同一套。折中：探索和学习绑在一起。
- **离线策略（off-policy）**：用一套策略去乱跑收集经验，用另一套去学「最好该怎么走」。探索和学习分开，通常更强。

---

## 马尔可夫过程（智能体行为）

把「智能体在环境里过日子」拆成这几个零件。马尔可夫：下一步只看现在，不翻旧账。

| 符号 | 是什么 |
|---|---|
| 状态 $s$ | 现在环境长什么样（常可离散成格子、档位） |
| 状态空间 $S$ | 所有可能状态 |
| 动作 $a$ | 在这个状态下能做的事，做完状态会变 |
| 动作空间 $A$ | 所有动作 |
| 转移 | $s_1 \xrightarrow{a_2} s_2$ |
| 策略 $\pi$ | 某个状态下，各个动作的概率分布。不是「选没选某个动作」，是整张骰子 |
| 回报 $r$ | 走完这一步的打分，正奖负罚 |
| 轨迹 | 状态–动作–回报串起来的一条路 |
| 返回值 $G$ | 这条路以后所有回报的打折总和 |

策略：

$$\pi(a_1 \mid s_1) = p(a_1 \mid s_1)$$

轨迹长这样：

$$S_1 \xrightarrow[r=0]{a_3} S_4 \xrightarrow[r=-1]{a_3} S_7 \xrightarrow[r=0]{a_2} S_8 \xrightarrow[r=+1]{a_2} S_9$$

返回值（$\gamma \in [0,1)$ 压住遥远的未来，防止无限加下去）：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots$$

也可拆成「眼前这一口 + 打折后的以后」：

$$G_t = R_{t+1} + \gamma G_{t+1}$$

## 状态值公式（状态回报评估公式）

一个状态值多少钱：从这个格子出发，以后能攒多少分的期望。**刚踏进这个状态的那一下分，不算在里面**，从下一步开始计。

$$v(s_i) = \mathbb{E}[G_t \mid S_t = s_i]$$

指定策略 $\pi$ 之后，要按「每个动作多常走」加权：眼前的分 + 走到下一格后的价值。

$$V_\pi(s) = \sum_a \pi(a \mid s) \left[ \sum_r p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, V_\pi(s') \right]$$

这就是贝尔曼期望方程：格子的价钱 = 这一步的平均分 + 折扣 × 下一格的平均价钱。

有模型、转移能写成矩阵时，收成一行：

$$v = r + \gamma P v$$

$r$ 是各状态的即时回报向量，$P$ 是转移矩阵，$v$ 是要解的价值向量。四个格子绕圈走时，就是 $V_1 = r_1 + \gamma V_2$ 这种，叠起来就是上面那条。

推导只靠一件事：未来还能再拆。再加一条马尔可夫——到了 $s'$ 之后，以前怎么来的不影响以后的期望：

$$G_t = R_{t+1} + \gamma G_{t+1}$$

$$\mathbb{E}(G_{t+1} \mid S_t, S_{t+1} = s') = \mathbb{E}(G_{t+1} \mid S_{t+1} = s')$$

---

### 动作值公式

状态值问「站在这儿值多少」；动作值问「在这儿做这件事值多少」。

$$q_\pi(s, a) = \mathbb{E}[G_t \mid S_t = s,\ A_t = a]$$

也就是从 $t$ 起把后面的折扣回报加起来再取期望：

$$q_\pi(s, a) = \mathbb{E}\left[\sum_{k=0}^{T-t} \gamma^k R_{t+k+1}\right]$$

状态值是动作值按策略加权：

$$v_\pi(s) = \sum_a \pi(a \mid s)\, q_\pi(s, a)$$

动作值表填满了、各动作概率也定了，状态值就定了。后面学策略，多半是在改这张 $q$ 表。

---

## 贝尔曼最优公式

最优策略：每个状态都不比别的策略差，总分最高。记作 $\pi^*$。

想总分最大，别把概率洒在烂动作上，**把筹码全压在 $q$ 最大的那个动作**：

$$\max_\pi \sum_a \pi(a \mid s)\, q(s, a) = \max_a q(s, a)$$

所以最优策略可以是确定的：

$$\pi(a \mid s) = \begin{cases} 1 & a = a^* \\ 0 & a \neq a^* \end{cases}
\qquad
a^* = \arg\max_a q(s, a)$$

对应的最优状态值：

$$v^*(s) = \max_a q^*(s, a)$$

$$q^*(s, a) = \sum_r p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v^*(s')$$

收缩映射保证：最优价值唯一，而且可以迭代逼近。

## 值迭代与策略迭代

差别就一句：**先把值算清楚再改走法，还是先按走法改值。** 两边都在「评估」和「改进」之间转圈（广义策略迭代）。

---

### 先算策略

策略迭代：手里有一套走法 $\pi_k$，先问「这套走法到底值多少」（评估到收敛），再按这张价值表贪心换成更好的走法，再评估，再换。

**策略改进（贪心）**——当前价值 $v_k$ 当成已知，挑让「眼前分 + 折扣下一格」最大的动作：

$$\pi_{k+1} = \arg\max_\pi \bigl( r_\pi + \gamma P_\pi v_k \bigr)$$

对每个状态：

$$\pi_{k+1}(s) = \arg\max_\pi \sum_a \pi(a \mid s)\, q_k(s, a)$$

$$q_k(s, a) = \sum_r p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v_k(s')$$

贪心结果是确定策略：只给 $a^*_k(s) = \arg\max_a q_k(s, a)$ 概率 1。

**策略评估**——走法先冻住，反复刷价值，直到几乎不动：

$$v_{\pi_k}^{(j+1)} = r_{\pi_k} + \gamma P_{\pi_k} v_{\pi_k}^{(j)}$$

$$v_{\pi_k}^{(j+1)}(s) = \sum_a \pi_k(a \mid s) \left( \sum_r p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v_{\pi_k}^{(j)}(s') \right)$$

停：$\|v^{(j+1)} - v^{(j)}\|$ 足够小，或 $j$ 够大。

实务上常维护一张动作值表，避免每次从转移里重算。循环：改进策略 → 评估价值 → 再改进。

---

### 先算值

值迭代：不把某套策略评估到死，每一步直接对动作取 max，把价值往最优推。值差不多稳了，再贪心抠出策略。

$$v_{k+1}(s) = \max_a \left[ \sum_r p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v_k(s') \right]$$

向量写法：

$$v_{k+1} = \max_\pi \bigl( r_\pi + \gamma P_\pi v_k \bigr)$$

拆开看，其实还是「先 implicit 选一下最好动作，再更新值」，只是不单独把策略评估完整。所以：**值迭代 = 每步先刷值；策略迭代 = 每轮先定策略。**

## 蒙特卡洛算法（无模型估计思想）

没有 $P$、没有 $r$ 的公式，只拿完整一局的结局当数据。有模型叫「知道地图」，蒙特卡洛叫「走很多遍，用平均当真相」。大数定律：试得够多，平均值贴近期望。

---

### mc basic

一局必须能结束。动作值用「从这次访问起，后面所有折扣回报加总」来估——所以适合**从终点往回扫**。

$$q_\pi(s, a) \approx \frac{1}{N}\sum_{i=1}^{N} G^{(i)}$$

其中 $G$ 是某次在 $(s,a)$ 出现之后整段轨迹的返回值。这就是用采样近似：

$$q_\pi(s, a) = \mathbb{E}[G_t \mid S_t=s, A_t=a]$$

有明确转移公式 → 有模型；只有一堆轨迹 → 经验。大力出奇迹：同一格同一动作试够多次，均值就是它的价值。

---

### 充分利用轮数的算法

一局里路过的每个 $(s,a)$ 都是样本，不必只记开头那一次。每走完一轮就用这些 $G$ 更新 $q$，再改策略。轨迹中途也可以按新策略拐弯。

问题：老往好路上钻，有些格子再也走不到，最优解可能被晾在没人去的角落。所以用**软策略**（$\varepsilon$-贪心）：大部分时候走当前最好，留一小撮概率乱试。

$$\pi(a \mid s) = \begin{cases} 1-\varepsilon+\varepsilon/|A| & a = \arg\max_{a'} q(s,a') \\ \varepsilon/|A| & \text{其它} \end{cases}$$

$\varepsilon$ 大 → 更爱逛（像 MBTI 的 P）；$\varepsilon$ 小 → 更盯着眼前最优。探索和最优是一笔买卖。

## 随机附近与随机梯度下降(无模型迭代)

没有模型时，方程解不了，只能拿带噪声的观测，一脚一脚把未知数踢向零点。

---

### 迭代公式推导

最大似然的直觉：随机事件次数无限多，频率贴上概率。迭代则是：每次用新观测修正旧估计，而不是攒齐所有数据再算一次。

---

### 随机逼近（观测值迭代）

Robbins–Monro：把 $g(w)=0$ 的根，用带噪观测 $\tilde g$ 去逼。

$$w_{k+1} = w_k - a_k\, \tilde g(w_k, \eta_k), \qquad \tilde g = g(w_k) + \eta_k$$

$w$ 是你关心的未知数（价值、权重），$\eta_k$ 是观测噪声——不必把噪声模型写出来，它客观存在。没模型就得靠数据。

收敛要三个脾气：

1. $\sum a_k = \infty$：步子总和够长，能走到任意远的 $w^*$。
2. $\sum a_k^2 < \infty$：后面步长趋于 0，不会一直抖。
3. $g$ 别弯得太疯（曲率有界一类条件）。

$a_k = 1/k$ 刚好满足前两条。

---

### 梯度下降方法总结

训练参数时，用损失对参数的梯度往山下走。批量：一次用全部样本，稳但贵。随机：一次用一个或一小批，便宜，是大规模网络的默认。

$$w_{k+1} = w_k - \alpha_k \nabla_w J(w_k)$$

随机梯度有采样误差。离最优点远时，方向大致对；靠近了，噪声相对变大，会在谷底打转——所以后半段要把学习率收小。批量和随机之间可以折中：小批量（mini-batch）。

---

## 时序差分方法

把「解贝尔曼方程」改成「找函数的零点」，用观测一步步更新期望。不必等一局结束：走一步，用**下一格的当前估计**当未来，这叫 bootstrap。

状态没被走到就不更新。含义：新估计 = 旧估计，朝「眼前分 + 折扣×下一格的现估价」挪一小步。

$$v_{k+1}(s) = v_k(s) - \alpha_k \bigl( v_k(s) - [r_k + \gamma v_\pi(s'_k)] \bigr)$$

真 $v_\pi(s')$ 不知道，就换成手头的 $v_k(s')$：

$$v(s) \leftarrow v(s) + \alpha \bigl[ r + \gamma v(s') - v(s) \bigr]$$

方括号叫 TD 误差：目标减当前。只看一步未来。样本改成轨迹上的 $(s_t, r_{t+1}, s_{t+1})$ 即可。

贝尔曼期望给的是「某个策略下状态值该满足什么」；TD 是用数据、一步一步去满足它。误差会往 0 赶（学习率合适时）。

---

### sarsa算法

把 TD 从「格子的价值」换成「格子+动作的价值」。名字就是那五个字母：State, Action, Reward, State, Action。

经验：$(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$。只用实际下一步**真的做了**的 $a_{t+1}$。

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) + \alpha_t \bigl[ r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1}) - q_t(s_t, a_t) \bigr]$$

其它没走到的 $(s,a)$ 不动。$q_t \to q_\pi$。这是在线策略：更新用的下一步动作，就是你正在执行的策略抽出来的。

套上策略迭代：用 $\varepsilon$-贪心由 $q$ 得到 $\pi$，再按 SARSA 更新 $q$，转圈。

变式 SARS：有时先到 $s'$ 再决定 $a'$；多步 SARSA 则把「一步 $r+\gamma q$」换成 $n$ 步返回值再接到 $q$ 上。

---

### q_learning

和 SARSA 几乎同一副骨架，只换 TD 目标：不管你下一步真打算走哪，更新时假装走**下一格最好的那个动作**。

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) + \alpha_t \Bigl[ r_{t+1} + \gamma \max_{a \in A} q_t(s_{t+1}, a) - q_t(s_t, a_t) \Bigr]$$

| | TD 目标 |
|---|---|
| SARSA | $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$ |
| Q-learning | $r_{t+1} + \gamma \max_a q_t(s_{t+1}, a)$ |

Q-learning 总在追「理想最优」，解的是贝尔曼最优，不是当前策略的期望。所以它是**离线策略**：行为可以 $\varepsilon$-贪心乱逛，更新却朝着 $\max$ 去，不绑死在行为策略上。

---

## 值函数近似

状态太多，表会爆。用带参数的函数冒充价值表，像泰勒：不存每一个点，存一套能算出点的系数。$\theta$ 或 $\omega$ 就是权重。

$$\hat v(s, \omega) \approx v_\pi(s)$$

$s$ 是随机变量，不同状态出现频率不同。若假装均匀，损失是各状态误差的平均；更合理的是按策略下的稳态分布 $\mu_\pi$ 加权——常走的格子权重大。这个分布来自转移矩阵的稳态。

目标：让估计贴上真值。

$$J(\omega) = \mathbb{E}\bigl[\bigl(v_\pi(S) - \hat v(S,\omega)\bigr)^2\bigr]$$

梯度下降：

$$\omega_{k+1} = \omega_k - \alpha_k \nabla_\omega J(\omega_k)$$

$$\nabla_\omega J(\omega) = -2\,\mathbb{E}\bigl[(v_\pi(S)-\hat v(S,\omega))\,\nabla_\omega \hat v(S,\omega)\bigr]$$

线性近似：特征 $\phi(s)$（多项式、傅里叶都行）

$$\hat v(s,\omega) = \phi(s)^\top \omega, \qquad \nabla_\omega \hat v = \phi(s)$$

真 $v_\pi$ 仍没有，用 TD 目标代替，得到半梯度 TD：

$$\omega_{t+1} = \omega_t + \alpha_t \bigl( r_{t+1} + \gamma \phi(s_{t+1})^\top \omega_t - \phi(s_t)^\top \omega_t \bigr) \phi(s_t)$$

线性的好处：你得对特征有直觉，但理论能分析。特征不够就加多项；还不够，换神经网络——它能贴任意非线性，把 $\omega$ 藏进层里，$s$ 进，$\hat v$ 出。

值函数近似下的 SARSA：同样的 TD，只是 $q$ 也变成 $\hat q(s,a,\omega)$，用 $\nabla_\omega \hat q$ 去更新。

Q-learning 的函数近似同一套路，目标里带 $\max_a \hat q(s',a,\omega)$。深度网络来当这个黑盒，就是下面的 DQN。

---

### DQN

目标函数（均方）：

$$J(w) = \mathbb{E}\left[\left( \bigl(R + \gamma \max_{a'} \hat q(S', a', w)\bigr) - \hat q(S, A, w) \right)^2\right]$$

别扭之处：参数 $w$ 既在预测里，又在目标 $y$ 里。目标会跟着你一起跑，像追自己的影子。做法：当半梯度，算梯度时把 $y$ 当成常数；再单开一个**目标网络** $w^-$，更新得比主网络慢。

$$y = R + \gamma \max_{a'} \hat q(S', a', w^-)$$

**经验回放**：把 $(s,a,r,s')$ 丢进池子，随机抽一批来训。打散轨迹里的前后相关，离线策略也能把旧经验嚼好几遍。

主网络常更新，目标网络隔一段把主网络的权重复制过来。两件事一起，才把「移动靶 + 相关样本」按住。

## 策略梯度方法

前面多半在学「值」，策略是从值上贪心抠出来的。这里直接把策略写成 $\pi(a \mid s, \theta)$，对 $\theta$ 做**梯度上升**（往分高的方向走）。

表现 $J(\theta)$ 可以是平均状态值 $\bar v_\pi$、平均每步奖励 $\bar r_\pi$、或起始状态价值 $\bar v_\pi^0$。它们在梯度上常常成比例，所以对回报评估和对状态值评估，方向是一回事。

策略梯度定理（$\eta(s)$ 是状态的分布或权重）：

$$\nabla_\theta J(\theta) \;\propto\; \sum_s \eta(s) \sum_a \nabla_\theta \pi(a \mid s, \theta)\, q_\pi(s, a)$$

写成期望更好采样：

$$\nabla_\theta J(\theta) = \mathbb{E}_{s\sim\eta,\, a\sim\pi}\bigl[ \nabla_\theta \ln \pi(a \mid s, \theta)\, q_\pi(s, a) \bigr]$$

上升一步：

$$\theta_{t+1} = \theta_t + \alpha \nabla_\theta J(\theta_t)$$

随机版：用刚经历的 $(s_t, a_t)$ 代替期望——「这个动作分高，就提高它的概率」：

$$\theta_{t+1} = \theta_t + \alpha\, \nabla_\theta \ln \pi(a_t \mid s_t, \theta_t)\, q_\pi(s_t, a_t)$$

---

### reinforce

用整局返回值 $G_t$ 代替 $q$，从终点往回传，不需要价值网络。

$$\theta \leftarrow \theta + \alpha\, \gamma^t G_t\, \nabla_\theta \ln \pi(a_t \mid s_t, \theta)$$

$G_t$ 和 $\pi$ 还 ste 在同一条轨迹上，方差大。$s$ 从 $\eta$ 来、$a$ 从 $\pi$ 来，都可以采样。想降方差，后面会换成优势 $A_t = G_t - b(s_t)$，或改用 Actor-Critic 的 $q$、$V$。

---

## actor_critic方法

还是策略梯度那一套，把「打分的人」和「做动作的人」拆开：

- **Actor**：更新 $\theta$，改 $\pi$
- **Critic**：估 $q_t(s,a)$ 或 $V(s)$，给 Actor 当秤

$$\theta_{t+1} = \theta_t + \alpha\, \nabla_\theta \ln \pi(a_t \mid s_t, \theta_t)\, q_t(s_t, a_t)$$

Critic 自己常用 TD 更新。比 REINFORCE 能每步学，不必等一局结束。

---

## PPO算法

策略梯度步子太大，新策略会跑飞。PPO 给更新加一根皮带：新旧策略的概率比不能离 1 太远。

$$r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t \mid s_t)}$$

$$\hat A_t \approx q_t - V_t \quad \text{（这步比平均好多少）}$$

$$L^{\mathrm{CLIP}}(\theta) = \hat{\mathbb{E}}_t \left[ \min\bigl( r_t(\theta)\hat A_t,\ \mathrm{clip}(r_t(\theta), 1-\varepsilon, 1+\varepsilon)\hat A_t \bigr) \right]$$

$r_t$ 是新旧概率比；clip 把比卡在 $1\pm\varepsilon$（$\varepsilon$ 常取 0.1～0.3）；$\min$ 取「不剪」和「剪过」里更保守的那个，好动作还能学，但不允许一次改疯。

PPO clip（把 $r_t$ 卡住，更新稳定）

起点就是：一条轨迹 $\tau$ 的期望回报

$$J(\theta) = \mathbb{E}_{\tau \sim P_\theta(\tau)}[R(\tau)] = \sum_\tau R(\tau)\, P_\theta(\tau)$$

$\tau$ 是整条状态–动作序列，$P_\theta(\tau)$ 是策略 $\pi_\theta$ 生成它的概率。目标：把这个期望拉最大。后面每一步都是为了让这个式子能用采样、能稳着更新。
